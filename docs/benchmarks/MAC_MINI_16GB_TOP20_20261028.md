## Recommended profiles

1. **Balanced default:** `gemma-4-E4B-it-Q6_K`. It leaves enough unified
   memory for BunkerAI services, context and Metal buffers while retaining a
   strong v3.1 score.
2. **Maximum-quality experiment:** `Qwen3.8-27B-UD-IQ3_XXS`. Start with
   `8K–16K` context and a quantized KV cache; validate peak memory before 32K.
3. **High-quality Qwen with more margin:** `Qwen3.8-27B-IQ2_M`.
4. **Compact fallback:** `gemma-4-E4B-it-Q4_K_M`.
5. **Fast helper:** `Qwen3.5-4B-Q5_K_M` or `gemma-4-E2B-it-Q4_K_M`.

The GGUF size is not peak runtime memory. KV cache, compute buffers, Metal,
the operating system and BunkerAI services share the same 16 GB pool. Models
above 10 GiB should therefore be treated as constrained even though they pass
the file-size filter.
