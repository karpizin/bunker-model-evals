# Единый рейтинг моделей OpenClaw v2

Обновлено: 2026-10-16

Документ объединяет актуальные эталонные прогоны OpenRouter и архивные локальные
результаты OpenClaw hard suite на общей детерминированной шкале `Contract v2`.

Архивные ответы переоценены без повторного запуска моделей. Для повторных
локальных прогонов одной конфигурации оставлен лучший полный результат на 28
задачах. Свежий прогон DeepSeek и его исторический результат OpenRouter намеренно
оставлены отдельными строками: разница между ними показывает вариативность
одиночного прогона и серверного инференса.

`Semantic v2` указан только там, где действительно запускался независимый
семантический судья. Прочерк означает отсутствие оценки, а не нулевой результат.

## Как интерпретировать результаты

- Рейтинг отсортирован по `Contract v2`, поскольку только эта актуальная метрика
  доступна для всех полных архивных прогонов.
- Локальные конфигурации `Qwen3.5-122B` и `Qwen3.6-35B` отстают от лучшего
  внешнего эталонного результата всего на 2.4-3.4 процентного пункта.
- Свежий DeepSeek получил заметно меньше архивного запуска. Поэтому одиночный
  прогон нельзя считать устойчивой оценкой универсального качества модели.
- Это продуктовый регрессионный набор из 28 задач, а не общий тест интеллекта.
  Он прежде всего измеряет соблюдение runtime-контракта BunkerAI/OpenClaw и
  качество ответов в характерных продуктовых сценариях.
- Для публикационного сравнения потребуются повторные прогоны, семантическая
  оценка архивных ответов, доверительные интервалы и небольшая ручная проверка.
